## 🚀 Quick Start Deployment

### Backend Deployment (Django)

```bash
# 1. Clone and navigate
git clone <repo-url>
cd backend

# 2. Create virtual environment
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Set environment variables
export DJANGO_SECRET_KEY=$(python -c 'from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())')
export DJANGO_DEBUG=False
export DJANGO_ALLOWED_HOSTS="yourdomain.com,www.yourdomain.com"
export DJANGO_CORS_ALLOWED_ORIGINS="https://yourdomain.com"
export DATABASE_URL="postgresql://user:password@localhost:5432/edtech"
# ... set other required vars

# 5. Prepare database
python manage.py migrate
python manage.py collectstatic --noinput

# 6. Run with production WSGI server
gunicorn config.wsgi --bind 0.0.0.0:8000 --workers 4
```

### Frontend Deployment (Next.js)

```bash
# 1. Navigate to portal
cd portal

# 2. Install dependencies
npm install --legacy-peer-deps

# 3. Set environment variables
export NEXT_PUBLIC_API_BASE_URL="https://api.yourdomain.com/api"
export NEXT_PUBLIC_GOOGLE_CLIENT_ID="your-client-id.apps.googleusercontent.com"
export NEXT_PUBLIC_SUPABASE_URL="https://your-project.supabase.co"
export NEXT_PUBLIC_SUPABASE_ANON_KEY="your-anon-key"

# 4. Build for production
npm run build

# 5. Start production server
npm start
# or use PM2:
pm2 start "npm start" --name "edtech-portal" --instances max
```

## 🔑 Required Environment Variables

### Backend (.env or system environment)
```
# Core Django
DJANGO_SECRET_KEY=<generate-random-key>
DJANGO_DEBUG=False
DJANGO_ALLOWED_HOSTS=yourdomain.com,www.yourdomain.com
DJANGO_CORS_ALLOWED_ORIGINS=https://yourdomain.com

# Database (PostgreSQL recommended for production)
DB_ENGINE=postgres
DB_NAME=edtech_platform
DB_USER=postgres
DB_PASSWORD=<secure-password>
DB_HOST=db.example.com
DB_PORT=5432

# Frontend URL
FRONTEND_BASE_URL=https://yourdomain.com

# Google OAuth
GOOGLE_OAUTH_CLIENT_ID=<from-google-console>
GOOGLE_OAUTH_CLIENT_SECRET=<from-google-console>

# OpenAI (for AI tutor)
OPENAI_API_KEY=<your-openai-key>
AI_MODEL=gpt-4o-mini

# Email Service (SMTP)
EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=True
EMAIL_HOST_USER=noreply@yourdomain.com
EMAIL_HOST_PASSWORD=<app-password>
DEFAULT_FROM_EMAIL=noreply@yourdomain.com

# Redis/Celery
CELERY_BROKER_URL=redis://redis.example.com:6379/0
```

### Frontend (.env.local)

## 📞 Support & Troubleshooting

### Common Issues:

**Frontend build fails:**
```bash
cd portal
npm cache clean --force
rm -rf node_modules package-lock.json
npm install --legacy-peer-deps
npm run build
```

**Backend migrations fail:**
```bash
python manage.py migrate --noinput
python manage.py migrate --plan  # See what will happen
```

**Static files not loading:**
```bash
python manage.py collectstatic --noinput --clear
python manage.py findstatic <filename>
```

**Database connection errors:**
```bash
# Test connection
python manage.py dbshell
# or
psql postgresql://user:password@host:port/dbname
```
