## Key Production Notes

1. **Database:** Currently uses SQLite. For production with multiple users, migrate to PostgreSQL using `DB_ENGINE=postgres` environment variable.

2. **Redis:** Configure Redis for Celery task queue and caching.

3. **Email:** Update `EMAIL_BACKEND` to use SMTP in production (currently set to console output in development).

4. **Static Files:** Configure web server (Nginx, Apache) to serve static files from `backend/staticfiles/`.

5. **Media Files:** Configure S3 or cloud storage for user uploads (media files).

6. **CORS:** Ensure `DJANGO_CORS_ALLOWED_ORIGINS` matches your frontend domain exactly.

7. **Google OAuth:** Register your production domain with Google Cloud Console.

8. **Payment Integration:** Telebirr payment flow mentioned in footer is not yet implemented (Phase 3 feature).
